# Current risks and validation gates

- **License:** the user accepted the noncommercial DevKit dependency. Tutor's own code is MIT; the SDK and its notices under `vendor/siwc-devkit/` retain their custom noncommercial license. Commercial use is not covered.
- **Real macOS evidence:** the owner verified sign-in, model discovery, explicit response completion and credential reuse after restart on macOS 27.0.1 / M3 / GPT-6.1-Sol in #4. This is owner-reported manual evidence; no agent handled credentials. Expiry, locked-Keychain and revocation checks remain in #5. Never infer service success from simulated tests or partial output.
- **Platform validation:** Ubuntu and macOS CI passed on the merged shell. Linux remains supported for build/runtime and automated application testing, but live Linux authentication and protected-keyring persistence are explicitly unverified and no longer gate development. Container-only test sandbox flags must not become normal app launch behavior.
- **Credential storage:** credentials remain in the main-process SDK with OS encryption. Linux basic_text and unknown backends are rejected. Normal saved-credential reuse was verified manually on macOS; Linux protected persistence and locked-store recovery remain unverified. Synchronous safeStorage is deprecated but retained deliberately pending async-backend/rotation validation.
- **Structured output:** strict schemas remain unverified on the subscription route. The official local wrapper exposes text streaming, not JSON Schema configuration. No pedagogical engine is implemented.
- **Distribution:** no installers, signing, notarization, or release packaging are included. Runnable build assets need the installed local SDK and its dependencies/notices.
- **Data:** no materials, learning history, database or course UI yet. Prompt/response text lives only in window memory and is never automatically retried.

- **Simulation boundary:** the confirmed SDK-interface stub is planned in #3, not implemented yet. It must require an explicit development/test launch, visibly identify simulation, isolate its profile, make no real provider calls and never silently replace a failed real connection. Stubbed results cannot establish OAuth, entitlement or OS-encryption correctness.

# Require subscription-backed inference

Tutor must use officially supported inference covered by the learner's ChatGPT subscription. A separately billed API is not an acceptable fallback, even as an opt-in option. If official subscription access is unavailable or gated, finish the desktop shell and pause AI integration while documenting the blocker; do not substitute another billing model. This user decision supersedes the API fallback options in sections 9 and 16 of the initial brief.
